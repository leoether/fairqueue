# FairQueue

Fair dispatch for Jira. No more picking the same person.

Built with Atlassian Forge for Codegeist 2026 (Specialized Industries).

Field jobs pile up unassigned, and usually the same person gets picked again and again. FairQueue turns the backlog into a fair queue: every unassigned issue lines up, highest priority first. One click on "Assign next fairly" gives the top job to the teammate with the fewest active issues (longest since their last assignment wins ties). The workload panel updates instantly, every assignment is recorded in history, and the Queue position panel inside any issue shows exactly where it stands.
